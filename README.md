# Awesome Room Layout Planning

A small curated collection of room-planning tools, official documentation and a measurement worksheet for comparing furniture arrangements before moving anything.

Selection focuses on drawing a room, keeping dimensions consistent, placing furniture and inspecting the same arrangement in 2D and 3D. Descriptions refer to the linked resources; check each provider's current account and export terms before choosing a tool.

## Planning tools

- [3D Room Maker](https://3droommaker.com/) — Manual room planning in the browser, with living-room, bedroom and blank templates. Move, rotate, resize and recolour furniture, edit walls/doors/windows in 2D and inspect the result in 3D. Core editing is free without an account. Google sign-in adds private cloud saving and one new watermark-free 1600 × 1000 PNG per account per UTC day; existing exports can be downloaded again.
- [Floorplanner](https://floorplanner.com/) — Draw a floor plan and explore it with 3D visualization. Useful when comparing a furnished plan with its spatial appearance. The provider offers a basic account and optional project upgrades; consult its current pricing for export requirements.
- [Sweet Home 3D](https://www.sweethome3d.com/) — Arrange furniture on a 2D home plan while viewing changes in 3D. Its official site links desktop downloads and an online version.

## Step-by-step guides

- [Measured room-layout workflow](https://gitlab.com/cnvx.studio/3d-room-layout-guide) — A practical guide to starting a room, arranging furniture and saving a useful result in 3D Room Maker. Maintained by this collection's product team.
- [Sweet Home 3D user guide](https://www.sweethome3d.com/users-guide/) — Official instructions covering wall drawing, doors/windows/furniture, dimensions and the 3D view. A useful reference for learning the relationship between a plan and its preview.

## A worksheet you can use with any planner

1. Pick one unit. Record the room's usable interior width/depth, door position and opening direction, windows and fixed obstacles. Keep missing measurements marked as unknown.
2. List the same furniture for both options, with width and depth. A quarter-turn swaps those two dimensions.
3. Draw option A around one priority, such as an open walking route. Draw option B around another, such as facing a focal wall. Keep the inventory unchanged so the comparison is useful.
4. Check each furniture footprint against the room boundary, other furniture, door swings and the walking route. Write down gaps and any measurements still needed.
5. Inspect both options in 3D, then recheck critical dimensions in the real room. Save the preferred arrangement with its measurement notes so another person can understand it.

Example worksheet headings:

| Item | Width × depth | Option A position/orientation | Option B position/orientation | What to recheck |
| --- | --- | --- | --- | --- |
| Sofa | Supplied measurements | Against the long wall | Facing the focal wall | Door swing and route |
| Table | Supplied measurements | Beside the sofa | Across the seating area | Reach and clearance |

Positions in this example are prompts for comparison, not a completed design. Choose clearance targets for the actual people and setting, and obtain appropriate professional advice for construction or accessibility requirements.
